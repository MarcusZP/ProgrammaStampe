# Esempi dello studio

avvisi, convocazioni ordinarie e straordinarie, letture dell'acqua, deleghe, circolari, ecc.

**Privacy:** tutto il contenuto di questa cartella, tranne questo file, è escluso da git e
non finisce su GitHub. Puoi lasciare i dati reali.

Suggerimento: una sottocartella per tipo, per esempio `convocazioni/`, `avvisi/`,
`letture-acqua/`.
